# Opentern

A fast, local-first trading terminal: TradingView-class charts, and indicators and strategies in Pine Script®-compatible code, Python and more.

Early development. What works today:

- Live charts for crypto (Binance) and stocks, ETFs, indices and forex (Yahoo, delayed),
  any interval including custom ones like 7m or 45m, with scroll-back history.
- Candles, hollow candles, bars, line and area; pan, zoom, crosshair, log and percent scales.
- 62 of TradingView's built-in indicators, with TradingView's inputs, styles and levels,
  editable settings, saved defaults, chart templates and indicator templates.
- A watchlist with live prices, symbol search, and a demo mode (`opentern --demo`).

See `CLAUDE.md` for the plan.
