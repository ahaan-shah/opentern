Install in one line

Paste this into a terminal. It downloads the latest release, checks it, and puts Opentern in your apps.

$ curl -fsSL https://raw.githubusercontent.com/ahaan-shah/opentern/main/install.sh | sh
PS> irm https://raw.githubusercontent.com/ahaan-shah/opentern/main/install.ps1 | iex

Backtests that match, to the cent

An agent beside the chart

Standing on good shoulders

The window is egui, the scripts run on Opentern’s own Pine engine, Luau and QuickJS, and the market data comes from the exchanges and providers you choose. TradingView’s open-source ta library ships with it under the MPL 2.0.
